**🟩 ATURAN UNESCO UNTUK PENULISAN BUKU**

(UNESCO Editorial Guidelines – ringkasan praktis)

1. Struktur Buku harus jelas & konsisten
   UNESCO menganjurkan struktur standar:
   - Cover
   - Halaman judul
   - Kata pengantar / Preface
   - Daftar isi
   - Bab per bab (chapter) dengan subjudul konsisten
   - Lampiran (jika ada data)
   - Glosarium
   - Daftar pustaka
   - Indeks (opsional)

2️. Bahasa harus jelas, objektif, tidak ambigu
   
   Pedoman UNESCO:
   - Gunakan kalimat pendek, langsung, dan tidak bertele-tele
   - Hindari istilah teknis tanpa penjelasan
   - Gunakan bahasa netral dan tidak bias

     Satu istilah = satu makna, konsisten di seluruh bab
     (misal pakai “kode pos”, jangan kadang pakai “poskode”)

3️. Setiap data harus dapat ditelusuri (traceable)

UNESCO menekankan:

Jika menyebut angka, grafik, peta → sebutkan sumbernya

Jika memproses data SIG, sebutkan:
- sumber data
- metode (buffer, join, overlay, dll)
- perangkat (QGIS / ArcGIS)

➡️ Ini penting untuk bab metodologi pemetaan kode pos.

4️. Sitasi & Daftar Pustaka harus standar

UNESCO membolehkan beberapa format, tetapi menganjurkan:

APA style | Chicago style

Aturannya:
- Sitasi dalam teks harus konsisten
- Semua sumber yang disebut di bab harus muncul di daftar pustaka
- Hindari sumber tidak kredibel

5️. Gambar, Peta, dan Tabel harus diberi keterangan lengkap

UNESCO meminta:
- Judul
- Nomor gambar/tabel
- Sumber data
- Tahun data
- Penjelasan singkat

Contoh: Gambar 2.1. Peta Sebaran Kode Pos Kecamatan Bandung (2024).

Sumber: Data Pos Indonesia, diolah penulis menggunakan QGIS.

6️. Hak cipta (copyright) harus jelas

UNESCO menganjurkan:

- Hindari mengambil peta, foto, atau tabel dari sumber berhak cipta tanpa izin
- Jika memakai data resmi (misal Pos Indonesia / BPS), wajib mencantumkan: “Sumber: …, digunakan untuk tujuan edukasi”

7️. Standardisasi istilah & format

UNESCO menetapkan:

Gunakan format tetap untuk:
- Judul bab
- subjudul
- penomoran gambar
- penomoran tabel
- penomoran lampiran
- penulisan poin

Gunakan glosarium jika buku banyak istilah baru

8️. Layout yang mudah dibaca

Rekomendasi UNESCO:
1. Margin standar (2–2.5 cm)
2. Jenis huruf mudah dibaca (Times New Roman / Arial / Calibri)
3. Ukuran 11–12 pt untuk isi
4. Spasi 1.15 – 1.5
5. Hindari paragraf terlalu panjang

9️. Objektivitas & inklusivitas

UNESCO mendorong:
1. Tidak menyinggung kelompok tertentu
2. Hindari bahasa diskriminatif
3. Gunakan istilah inklusif dan akademik

10. Kualitas visual

Untuk buku SIG sangat relevan:
1. Peta harus terbaca (label, legenda, skala)
2. Warna tidak terlalu mencolok
3. Gunakan north arrow (penunjuk arah)
4. Gunakan standar legenda yang konsisten
